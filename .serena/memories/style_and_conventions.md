# Style and conventions
- Answer users in Japanese.
- New markdown files must include 作成日 and 作成者; updated markdown files must include 更新日.
- BAT files for users must stay ASCII-only.
- Japanese display text should live in UTF-8 BOM PowerShell scripts, not BAT.
- New PowerShell files containing Japanese should be UTF-8 BOM for PowerShell 5.1 compatibility.
- Respect existing V1/V2 separation in templates, profiles, handoff, samples, and scripts.
- Avoid broad refactors; prefer focused changes tied to the request.
- If UI/UX changes, update README.md or docs/user-manual.md.
