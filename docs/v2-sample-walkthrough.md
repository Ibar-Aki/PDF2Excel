# PDF2Excel V2 サンプル体験ガイド

- 作成日: 2026-03-20 10:45 JST
- 作成者: Codex (GPT-5)
- 更新日: 2026-03-20

このガイドは、`VER2 Secure` の使い方を短時間で学びながら、`Review` と `Errors` を含む V2 の利便性を実感できるようにした体験用手順書です。  
最初はこのガイドの順番どおりに試してください。

## 1. このガイドで分かること

- `run_pdf2excel.bat` だけで V2 を実行できること
- `construction_transfer_poc` プロファイルで複数ページ帳票をまとめて扱えること
- 正常行は `Result`、確認が必要な行は `Review`、処理不能な帳票は `Errors` に分かれること
- `sameHeader` により、危ない自動結合を避けながら転記できること

## 2. 事前準備

1. このフォルダをローカル PC に展開します。共有フォルダ上では実行しません。
2. Excel(M365) デスクトップ版が起動できることを確認します。
3. 必要なら [run_pdf2excel.bat](../run_pdf2excel.bat) を一度実行し、メニューの `[0] 環境チェック` を通してください。
4. V2 サンプルの置き場所を確認します。
   - PDF: [samples/v2/pdf/construction_transfer_poc](../samples/v2/pdf/construction_transfer_poc)
   - 元帳票: [samples/v2/source/construction_transfer_poc](../samples/v2/source/construction_transfer_poc)
   - プロファイル: [construction_transfer_poc.json](../config/profiles/v2/construction_transfer_poc.json)

## 4. 5 分体験手順

### 4-1. 基本成功パターン

1. [run_pdf2excel.bat](../run_pdf2excel.bat) をダブルクリックします。
2. メニュー上部の現在プロファイルが `生データ転記サンプルプロファイル` であることを確認します。
   - 違う場合は `[9] プロファイルを選ぶ` から `construction_transfer_poc` を選びます。
3. `[1] PDFファイルを選んで変換` を押します。
4. [2026年02月_作業員勤怠一覧_PoC.pdf](../samples/v2/pdf/construction_transfer_poc/2026年02月_作業員勤怠一覧_PoC.pdf) を選びます。
5. 保存先を `output\v2_sample_basic.xlsx` などで指定します。
6. 実行前チェックで、件数・保存先・使用プロファイル・簡易プレビューを確認して `Y` を押します。
7. 完了したら `O` を押して出力ファイルを開きます。

確認ポイント:

- `Summary` に対象 PDF 1 件、成功 1 件が出ること
- `Result` に元ファイル名付きの明細が入ること
- `Result` の末尾に `正規化入場*`、`正規化退場*`、`*_分` が追加されていること
- `Review` が空、または確認対象がないこと

### 4-2. 複数ページ結合パターン

1. もう一度 `[1] PDFファイルを選んで変換` を選びます。
2. [2026年02月_作業員勤怠一覧_PoC_2ページ同一列.pdf](../samples/v2/pdf/construction_transfer_poc/2026年02月_作業員勤怠一覧_PoC_2ページ同一列.pdf) を選びます。
3. 保存先を `output\v2_sample_merge.xlsx` などで指定します。
4. 実行後に `Summary` と `Result` を確認します。

確認ポイント:

- 2 ページ帳票でも、同じ列構成なら 1 つの結果として扱われること
- ページごとに分断されず、`Result` 側でそのまま集計や確認に使えること
- 利用者が手でページ結合しなくてよいこと

### 4-3. Review 分離パターン

1. もう一度 `[1] PDFファイルを選んで変換` を選びます。
2. [2026年02月_作業員勤怠一覧_PoC_時刻確認負例.pdf](../samples/v2/pdf/construction_transfer_poc/2026年02月_作業員勤怠一覧_PoC_時刻確認負例.pdf) を選びます。
3. 保存先を `output\v2_sample_review.xlsx` などで指定します。
4. 実行後に `Review` シートを開きます。

確認ポイント:

- 曖昧な時刻や欠損が `Review` に出ること
- `ReasonCategory` に `TIME_MISSING` や `TIME_INVALID` などが出ること
- `Result` には通常処理できた行が残り、全件停止にならないこと
- `時刻確認メモ` を見れば、どこを人が確認すべきか分かること

## 5. V2 の利便性を実感しやすい見どころ

### 見どころ 1: 1 回の操作で完了する

- BAT 起動
- PDF 選択
- 保存先選択
- 実行前チェック確認

この 4 ステップで、複数ページ帳票を Excel にまとめられます。

### 見どころ 2: 危ない自動判定を避ける

V2 は「何でも自動結合」ではありません。  
ヘッダーがずれた帳票は無理に `Result` に混ぜず、`Errors` や `Review` へ逃がします。

試す PDF:

- [2026年02月_作業員勤怠一覧_PoC_ヘッダー不一致負例.pdf](../samples/v2/pdf/construction_transfer_poc/2026年02月_作業員勤怠一覧_PoC_ヘッダー不一致負例.pdf)

見る場所:

- `Errors`
- `Review`

### 見どころ 3: 後工程に使いやすい

`Result` には raw 値だけでなく、分析や確認に使いやすい列も追加されます。

- `正規化入場*`
- `正規化退場*`
- `*_分`
- `時刻正規化状態`
- `時刻確認メモ`

これにより、手作業で時刻を並べ替え直す前処理をかなり減らせます。

## 6. おすすめの学習順

1. 基本成功パターンで、全体の操作を覚える
2. 複数ページ結合パターンで、V2 がページをまたいで使えることを確認する
3. Review 分離パターンで、人が見るべき行だけ切り出せることを確認する
4. ヘッダー不一致負例で、危ない帳票を無理に混ぜないことを理解する

## 7. 利用者向けの説明で使いやすい要約

V2 は、PDF を Excel に変えるだけのツールではありません。  
「そのまま使える行」は `Result`、  
「人が見るべき行」は `Review`、  
「処理不能な帳票」は `Errors` に分けることで、現場確認を前提にした安全な転記ができます。
