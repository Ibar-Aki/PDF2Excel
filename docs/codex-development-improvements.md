## 1. 目的

PDF2Excel の開発で実際に起きた問題と、`C:\AlphaArtEngine` の運用ルールを参考に、Codex 利用時の改善点を整理します。

## 2. 今回の開発で目立った問題

### 2-1. 文字コード起因の事故

一番大きかったのは、`run_pdf2excel.bat` に日本語を直接持たせたことで起きた文字化けです。

学び:

- `cmd.exe` は文字コード依存が強い
- 日本語を含む BAT は壊れやすい
- PowerShell 5.1 は BOM なし UTF-8 の `.ps1` でも事故が起きやすい

改善方針:

- BAT は ASCII のみ
- 日本語メニューは UTF-8 BOM の PowerShell 側へ逃がす

### 2-2. handoff との同期漏れ

本体だけ直しても、配布パッケージ側へ反映し忘れると、利用者の実物は直っていない状態になります。

改善方針:

- 起動ファイルを直したら `scripts/build_handoff_package.ps1` を必ず再実行する
- handoff 側の BAT / menu / profiles まで確認対象に含める

### 2-3. サンプル生成の副作用

`samples/pdf` 全体を初期化してしまい、既存サンプルが消える事故がありました。

改善方針:

- サンプル生成スクリプトは管理対象サブディレクトリだけを更新する
- 既存の固定サンプルは残す

### 2-4. 回帰テスト不足

文字化け問題のように、コードは通っても利用者画面で壊れる問題は、通常の変換テストだけでは見落としやすいです。

改善方針:

- BAT は ASCII のみ、menu は UTF-8 BOM、という形式要件をユニットテストで持つ
- BAT 変更時は BAT 経由ケースを必ず再実行する

## 3. `C:\AlphaArtEngine\AGENTS.md` から参考になった点

`C:\AlphaArtEngine\AGENTS.md` は、次の点が良いです。

- 目的が短く明確
- 作業ルールが少数で強い
- 「何を優先し、何を避けるか」が迷いにくい

この形は PDF2Excel にも有効です。  
特に PDF2Excel では、文字コード、配布物同期、テストの必須確認を短いルールとして固定すると効果が高いです。

## 4. PDF2Excel に対して実施した改善

今回、次を追加しました。

- プロジェクト専用の [AGENTS.md](../AGENTS.md)
- この改善メモ自体

`AGENTS.md` に入れた重点ルール:

- BAT は ASCII のみ
- 日本語は UTF-8 BOM の PowerShell へ逃がす
- BAT 変更時は handoff と BAT テストを確認する
- 新規プロファイル追加時はサンプルとテストを追加する
- サンプル生成時に既存サンプルを消さない

## 5. Skills の提案

今回の条件では、追加する skill は慎重でよいです。

### 5-1. 推奨

- `openai-docs`
  - OpenAI API や Codex 自体の使い方を確認するときだけ使う
  - 公式ドキュメント参照に限定できるので安全

### 5-2. 条件付き

- `skill-installer`
  - 今後、OpenAI 公式 curated skills の中から追加導入したいときだけ使う
  - 普段の PDF2Excel 開発では常用不要

### 5-3. 非推奨

- 非公式 skill の追加
  - 今回の条件では採用しないほうがよいです
- Anthropic 系を含む外部配布 skill
  - この環境では公式・安全性担保の確認コストが増えるため、今回は提案しません

結論として、現時点では「新しい skill を増やすこと」より「AGENTS とテストで運用を固めること」のほうが効果が大きいです。

## 6. おすすめ運用

今後の Codex 利用では、次の流れが良いです。

1. まず `AGENTS.md` のルールで事故を防ぐ
2. 変更のたびに、影響のある最小テストを回す
3. 利用者向けの変更は handoff まで同期する
4. OpenAI 製品の調査が必要なときだけ `openai-docs` を使う

## 7. 結論

今回の知見から見ると、PDF2Excel に必要なのは「多機能な skill の追加」よりも、

- プロジェクト専用 AGENTS
- 文字コードルール
- 配布物同期ルール
- 回帰テストの必須化

の 4 点です。

これらは、実際に起きた事故へ直接効く改善です。
